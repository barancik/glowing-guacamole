\chapter{Targeted Sentence Paraphrasing for MT Evaluation}
\label{prehistory}
%\addcontentsline{toc}{chapter}{Prehistory}
Automatic evaluation of machine translation systems is sensitive to lexical overlap between system outputs and reference translations. As discussed in previous chapters, this leads to systematic bias against valid translations that differ lexically or syntactically from the reference, particularly in morphologically rich languages such as Czech. One way to mitigate this bias is to increase the diversity of reference translations by introducing paraphrastic variants that preserve meaning while varying the surface form.

This chapter investigates \textit{targeted paraphrasing} of reference sentences as a method for reducing bias in automatic machine translation evaluation. We show that targeted paraphrasing can effectively increase the robustness of evaluation by reducing the mismatch between system outputs and reference translations. Unlike general-purpose paraphrasing, which aims to generate a broad range of alternative formulations, targeted paraphrasing focuses on producing reference variants that are lexically closer to system outputs while remaining grammatical and semantically equivalent. The goal is not to generate all possible paraphrases, but to selectively reduce evaluation bias by narrowing the gap between hypotheses and references.

In this chapter, we present several techniques for the targeted paraphrasing of Czech sentences to improve machine translation evaluation. The chapter is organized as follows. Before exploring different paraphrasing methods, \Cref{prehistory:data} introduces the datasets used across all experiments in this chapter. The initial method, described in \Cref{substitution}, adopts a simple substitution strategy directly inspired by \cite{kauchak}. This approach involves the substitution of words and phrases in reference sentences using paraphrase tables, while ensuring grammatical correctness and the original meaning of the resulting sentences. In \Cref{parmesan}, we apply this method to propose a new machine translation evaluation metric.

The subsequent sections explore the use of machine translation systems for targeted paraphrasing. There are notable similarities between translation and paraphrasing; both aim to preserve the meaning of a sentence while changing its form. While translation focuses on converting text from one language to another, paraphrasing achieves the same objective within a single language by using a different choice of words or syntactic structures. Both processes require a thorough understanding of the original content and the ability to accurately express the intended message while considering linguistic nuances, cultural context, and the target audience. Machine translation, however, benefits from a much wider variety of accessible tools and resources compared to the relatively limited availability of paraphrasing tools. Given this disparity, it is natural to consider repurposing existing machine translation systems for targeted paraphrasing within a single language.

The subsequent sections explore the use of machine translation systems for targeted paraphrasing. Translation and paraphrasing share a common objective: preserving meaning while altering surface form. While translation operates across languages, paraphrasing achieves this within a single language through lexical and syntactic variation. Because machine translation benefits from a wide range of mature tools and resources, it is natural to consider repurposing these systems for targeted paraphrasing.

\Cref{moses} presents experiments conducted using the freely available statistical machine translation (SMT) system Moses. Although its results are inconclusive, analysis of the generated reference sentences reveals systematic problems that motivate an alternative approach. \Cref{treex} therefore introduces targeted paraphrasing with components of a rule-based translation system implemented in the NLP framework Treex, which successfully mitigates many of the issues observed with Moses.

\section{Data}
\label{prehistory:data}
We use two types of data: (i) data from the Workshop on Machine Translation (WMT) to evaluate our experiments, and (ii) paraphrase tables, which provide the source material for targeted paraphrasing.

\subsection{Test Data}
Our experiments are conducted on several datasets from the English-to-Czech translation task of the WMT shared translation campaigns held between 2011 and 2014.

Each dataset consists of one file containing the original English source sentences, several files with Czech hypotheses (outputs produced by various MT systems), and one file with corresponding reference translations. The datasets vary across years in the number of participating MT systems and the official evaluation methodology, as shown in \Cref{wmt-data}. All hypotheses and reference sentences were morphologically analyzed and tagged using MorphoDiTa \citep{morphodita}.

As mentioned in \Cref{background}, during this period the manual evaluation of translated sentences was performed using the relative ranking method. However, the procedure for computing the absolute system scores varied from year to year as shown in \Cref{wmt-data}. We refer to these official WMT scores as the \emph{gold standard}. Therefore, to make our evaluation internally consistent, we additionally compute a common absolute score for every year. Specifically, we adopt the “$ >$ others” method \citep{bojar-grains}, which served as the WMT12 official system score. Throughout the whole \Cref{prehistory}, we refer to this method as the \emph{silver standard}.

\subsection{Czech Paraphrase Tables}
\label{sect:paraphrase-tables}
To the best of our knowledge, we considered all major available sources of Czech paraphrases at the time of our study. These include the \textit{Czech WordNet} \citep{czech-wordnet}, which provides a structured repository of synonyms. The database was constructed semi-automatically using electronic bilingual dictionaries, with candidate synsets undergoing manual review. However, its structure largely mirrors the English WordNet, and it exhibits known issues related to word-sense disambiguation.

Furthermore, the coverage of Czech WordNet is limited and insufficient for the scale required in our experiments. To address this limitation, we adopt \textit{\mpt} \citep{meteor-tables} as an alternative resource. While these tables are substantially larger, they are inherently noisy due to their automatic construction. 

It should be noted that we did not integrate the Paraphrase Database (PPDB) \citep{ppdb, pavlick-etal-2015-ppdb}, as it was released shortly after the completion of our experiments.


\subsubsection{Czech WordNet}
Czech WordNet, developed by the NLP Centre at the Faculty of Informatics, Masaryk University, is part of the EuroWordNet project \citep{eurowordnet}. Its primary objective is to create a semantic network that connects multiple languages through a shared core structure.

Czech WordNet contains 28,201 synsets, each representing a set of words or phrases that share an associated meaning within a given context. While some synsets include glosses (clarifying their meanings), the majority do not, as the initial focus was on establishing semantic relations rather than providing exhaustive lexical definitions. Efforts to fill these gaps have been reported by researchers such as \citet{Rambousek:2017}, who involved linguistics students in drafting missing definitions. However, these definitions have not yet been fully integrated into the released version of Czech WordNet.

The original, large version of Czech WordNet is available only under a closed, paid license distributed by the ELDA/ELRA agency. Therefore, in our experiments we use a smaller, corrected version --- Czech WordNet 1.9 PDT \citep{czech_wordnet_pdt}, which is publicly available in the LINDAT/CLARIN repository.\footurl{http://hdl.handle.net/11858/00-097C-0000-0001-4880-3} This version contains 23,094 synsets covering nouns, verbs, adjectives, and partly adverbs; 7,028 synsets include multiple entries, which can be considered paraphrases.

Czech WordNet was developed by mapping entries from existing electronic bilingual dictionaries to the Princeton WordNet \citep{wordnet,fellbaum98wordnet}, a process executed in several iterative cycles of automatic association and manual correction. While this process allowed for rapid creation of the database, it introduced several documented disadvantages \citep{1489838}. Because the mapping relied on bilingual dictionary equivalents, the resulting synsets often inherited the English structural hierarchy, which does not always align with Czech lexical nuances. This led to persistent issues with word-sense disambiguation and the inclusion of non-idiomatic multi-word expressions that function as literal descriptions rather than true lexical units, for example, \samppair{hřebíček na papír}{a little nail for paper}, \samppair{kára s jablky}{cart with apples} or \samppair{zapékaná klobása}{baked sausage}.

At the same time, Czech WordNet includes many useful paraphrases for frequently used words (such as \foreign{ambulance},  \foreign{sanitka}, \foreign{pohotovost}, \foreign{záchranka}, \foreign{sanita}, which can all be translated as \trans{an ambulance}). However, it also contains archaic or rarely used phrases, which may limit its applicability in contemporary MT evaluation. Furthermore, certain synsets — particularly those referring to proper names (e.g., the apostles as \trans{Matthew}-\trans{Saint Matthew}-\trans{Saint Matthew the Apostle}) were left untranslated.  Examples of synsets containing rarely used or even erroneous entries are presented in \Cref{divny_wordnet}.

\subsubsection{\meteor paraphrase tables} 
\label{meteori}
The \meteor paraphrase tables were created as a resource for the \mn machine translation evaluation metric \citep{meteor-tables}. They are available for five languages: Czech, English, German, French, and Spanish. For languages lacking direct support, \cite{denkowski-lavie-2014-meteor} introduced an automatic tool for extracting paraphrase tables from parallel corpora.

All \meteor paraphrase tables are automatically generated from parallel data via the \textit{pivot phrase method} \citep{pivoting}. This method is based on a simple principle: if two phrases in a source language ($s_1,s_2$) frequently translate to the same phrase ($f$) in a \textit{pivot language} (typically English), they likely share a similar meaning. The total probability of $s_2$ paraphrasing $s_1$, also called a \emph{pivot score} (PS), is given as the sum over all $f$:

\begin{equation*}
P(s_2 \mid s_1) = \sum_{f} P(f \mid s_1) \, P(s_2 \mid f), 
\end{equation*}
where the sum aggregates over all pivot phrases $f$ that co-occur with both source phrases in the parallel data. The individual probabilities are derived from phrase alignment frequencies in the training corpora, Europarl \citep{koehn-2005-europarl} and CzEng 1.0 \citep{czeng10:lrec2012}.

All pairs of paraphrase candidates and their pivot scores are collected in the resulting tables. Higher scores indicate stronger evidence that the two phrases are valid paraphrases: the more frequently both $s_1$ and $s_2$ align to the same pivot phrase(s), and the more consistent these alignments are across the corpus, the higher the pivot score.

While the original Czech \mpt introduced in \cite{meteor-tables} contains 756,113 paraphrase pairs, our experiments utilize a later release (version 1.3; \citealp{meteor-wmt:2011}), which introduces a more compact, filtered subset of 683,584 pairs. However, even with this internal filtering, considerable noise remains in the resulting pairs. For instance, 28\% of all entries consist merely of different word forms of the same lemma rather than true lexical alternatives. While this redundancy facilitates the \mn flexible matching, it also significantly limits the lexical diversity of the tables.

Several factors contribute to this noise, including misaligned sentences in the source corpora, errors in phrase alignment, and semantic ambiguity. The last type is particularly evident in pairs such as \samppair{znásilnění}{rape; as a form of sexual assault} vs. \samppair{řepka}{rape; as a cultivated plant} or \samppair{netopýr}{bat; as a flying mammal} vs. \samppair{pálka}{bat; as a sport equipment}, where words with identical surface forms in the pivot language but distinct meanings are incorrectly identified as paraphrases. 

Noise is most evident among low-pivot-score pairs and multi-word expressions; however, it also occur among one-word entries. We present examples in \Cref{meteor_noise}.

We attempt to minimize non-paraphrastic pairs in \cmt using two different methods. The first one, applied specifically to pairs of one-word paraphrases, is based on manual error analysis, and we refer to the resulting tables as \fm. The second method is fully automatic and applicable to all data; however, its results are inconclusive. This automatic filtering method is detailed further in Appendix \nameref{filtering-section} as it depends on paraphrasing methods that need to be introduced first. 
In this section, we present only the first method, which is applied consistently in all our experiments.

\subsubsection{Filtered Meteor}
\label{filtered_meteor}
Based on our observations, we perform the following operations on pairs of one-word paraphrases from \mpt:

\begin{enumerate}
    \item \textbf{morphological analysis:} We perform morphological analysis using Morče \citep{morce:2007}, a tool for morphological disambiguation of Czech text, and replace word forms with their lemmas.
    \item \textbf{identical lemmas removal:}  Pairs with identical lemmas are eliminated.
    \item \textbf{different POS removal:}  Pairs with different parts of speech are removed.
    \item \textbf{unknown words removal:}  Pairs involving words not known to the morphological analyzer, typically foreign words, are eliminated.
\end{enumerate}

However, an exception to the last two rules was made for paraphrases consisting of numerals and corresponding digits (e.g., \samppair{osmnáct} {eighteen} and \textit{18}). These pairs, denoted by the part of speech C for numerals and X for unknown words, were preserved due to their prevalence and quality as paraphrases.

By applying these rules, we successfully reduced the initial pool of over 160,000 pairs of one-word paraphrases to a refined set of 32,154 pairs of lemmas, effectively addressing all examples of inadequate one-word paraphrases from \Cref{meteor_noise}.

We use both filtered and unfiltered versions of the Czech \meteor paraphrase tables in our experiments. To avoid ambiguity, we adopt the following labelling throughout this work:

\begin{itemize}
    \item \textbf{\wordnet{}:}  Czech WordNet 1.9 PDT. Used for both one-word and multi-word substitution experiments.
    \item \textbf{\fm{}:} Lemmatized and filtered subset of \cmt containing 32k pairs of one-word paraphrases. Used exclusively in one-word paraphrasing experiments.
    \item \textbf{\cmpt{}:} The original, unfiltered Czech \textsc{Meteor} paraphrase tables (684k pairs). Used for multi-word experiments. It is used in scenarios with multi-word paraphrases.
    \item \textbf{\mn{}:} The machine translation evaluation metric. Unless otherwise specified, it utilizes its default \cmpt{} resource for internal matching.
\end{itemize}
