\section{Automatic Translation Evaluation}
\label{rw}

Given the complexity and limitations of human evaluation discussed in the previous section, automatic evaluation aims to approximate translation quality in a scalable, efficient, and reproducible way. While human evaluation remains the gold standard, its cost, variability, and limited reproducibility make it impractical for iterative system development, where frequent, consistent, and repeatable evaluation is required for tuning and large-scale benchmarking.

As a result, automatic metrics have become a central component of MT research. Their primary goal is to assign numerical scores to translations, which are then used to rank systems according to their agreement with human judgments. The effectiveness of such metrics is commonly evaluated by measuring their correlation with human assessments.

Similarly to a human annotator, automatic MT metrics typically receive the following inputs:
\begin{itemize}
    \item the translation \textit{hypothesis} generated by the MT system,    
    \item one or more human-produced \textit{reference} translations, and
    \item optionally, the original \textit{source} sentence.
\end{itemize}
 
Early MT evaluation relied almost exclusively on reference-based comparison using surface-level lexical overlap, often ignoring the source sentence. However, recent metrics based on neural embeddings and large language models are increasingly incorporating source-side information to better evaluate meaning preservation. Furthermore, while \textit{reference-free} evaluation, also known as \textit{quality estimation}, historically performed worse than reference-based metrics, this distinction has substantially blurred. Recent neural and LLM-based metrics have shown that reference-free approaches can rival or even outperform reference-based methods \citep{freitag-etal-2021-results, rei-etal-2021-references, Moosa2024MTRankerRM}.

This evolution reflects a shift from explicit surface matching toward learned representations of semantic adequacy and direct modeling of human preferences. While embedding-based metrics approximate semantic similarity, preference-trained and LLM-based approaches aim to model human judgment more directly, either through learned ranking or generative reasoning. In the following sections, we review this development, beginning with traditional string-based metrics and progressing toward more modern evaluation methods. MT metrics can be broadly categorized into the following paradigms:

\begin{itemize}
    \item \textbf{lexical overlap} metrics (e.g., \bleu, \ter, \chrf)
    \item \textbf{lexical overlap with linguistic resources} (e.g. \mn, \terp)
    \item \textbf{embedding-based similarity} metrics (e.g., \bertscore)
    \item \textbf{supervised neural encoder-based} metrics trained on human judgments (e.g., \comet,\bleurt)
    \item \textbf{probabilistic} metrics (e.g., \prism)
    \item \textbf{LLM-based evaluators} (e.g., \textsc{MetricX}, \textsc{GEMBA})
    \item \textbf{preference-trained and reward-model} metrics (e.g., \mtranker, \remedy)
\end{itemize}

Following the automatic evaluation metrics, we review methods for generating paraphrases of reference sentences, to increase the diversity of reference sets and reduce evaluation bias. These methods include human-authored paraphrases, rule-based systems, and neural paraphrase generation techniques such as back-translation and transformer-based models. By creating multiple reference variants, these approaches help reduce evaluation bias against valid but non-literal translations and improve alignment with human preferences.

Together, these two perspectives, automatic evaluation metrics and paraphrased references, show how paraphrasing affects the evaluation of machine-translated output into more robust and reliable assessment frameworks. This connection is central to this thesis, which examines how increasing reference diversity through paraphrasing affects the reliability of automatic evaluation.

\subsection{String-based metrics}
Traditional MT evaluation metrics quantify similarity between a system output and a reference translation using surface-level string overlap. Their main advantages include:

\begin{itemize}
    \item \textbf{Low computational cost:} They rely on efficient string-matching algorithms at the character and/or token level. While some metrics might involve token shifting, which could be more resource-intensive for long translations, their calculation is easily parallelizable and does not require GPU processing.
    \item \textbf{Reproducibility:}  Their behavior is deterministic and well-defined.
    \item \textbf{Explainability:} Traditional metrics are straightforward to compute and understand, particularly for short segments. This transparency is helpful in error analysis and debugging.
    \item \textbf{Language Independence:} Most traditional metrics are designed to be language-agnostic and require no language-specific resources.
\end{itemize}
    
However, traditional metrics also come with substantial disadvantages:
\begin{itemize}
    \item \textbf{Reliance on lexical similarity:} Their fundamental limitation lies in equating translation quality with lexical similarity. Because translation is inherently paraphrastic, multiple valid translations may use different lexical choices while preserving the same meaning. String-based metrics therefore tend to penalize legitimate lexical variation, failing to reward synonyms or paraphrases that do not match the reference surface forms.
    \item  \textbf{Poor Correlation with Human Judgments:} Large-scale comparisons (e.g. \citealp{mathur-etal-2020-tangled, freitag-etal-2022-results}) show that lexical overlap metrics correlate substantially worse with human judgments than modern neural alternatives, especially at the segment level.
    \item \textbf{Tokenization and Implementation Inconsistencies:} Traditional metrics often rely on pre-tokenized input, and tokenization is handled outside the metric itself. As a result, the scores can vary depending on the specific tokenization pipeline used. Furthermore, multiple implementations of these metrics exist, some of which differ subtly or significantly in their behavior. These inconsistencies can lead to misleading or non-reproducible results. To address this, \citet{post-2018-call} introduced the SacreBLEU\footurl{https://github.com/mjpost/sacrebleu} framework, which standardizes tokenization and metric computation for reproducible evaluation.
\end{itemize}

\subsubsection{\bleu}
\bleu (BiLingual Evaluation Understudy; \cite{papineni-etal-2002-bleu}) is one of the earliest and most widely adopted automatic metrics in machine translation. It is based on the hypothesis that even though there are many different ways to correctly translate a sentence, high-quality translations will tend to share overlapping unigrams and n-grams (i.e., contiguous word sequences of length n) with reference translations. The metric was originally designed with multiple reference translations in mind, under the assumption that a set of references would approximate a more complete representation of valid translation variants. However, in practice, most MT evaluations use only a single reference, severely limiting the effectiveness of \bleu.

\bleu is defined as the geometric mean of \textit{modified n-gram precisions} ($p_n$), scaled by a brevity penalty (BP) to prevent a bias toward short hypotheses. Modified precision clips the count of each n-gram in the hypothesis by its maximum frequency in the reference. This prevents artificially inflating scores by repeating a single high-confidence word (e.g., \trans{the the the the}). It does not explicitly incorporate recall, as defining recall in the presence of multiple references is non-trivial. To compensate for missing recall, \bleu includes a brevity penalty (BP), discouraging too short hypotheses.

$$\text{\bleu} = \text{BP} \cdot \exp\left( \sum_{n=1}^{N} w_n \log p_n \right),$$ where $w_n$ is the weight assigned to each precision (typically $w_n=\frac{1}{N}$ for uniform weighting, $N$ is the maximum n-gram length, typically $N=4$), hypothesis length and effective reference length. For hypothesis length $c$ and effective reference length $r$, the brevity penalty is:

$$\text{BP} = 
\begin{cases}
1 & \text{if } c > r \\
e^{(1 - \frac{r}{c})} & \text{if } c \leq r
\end{cases}
$$

The reliability of \bleu has been increasingly challenged, particularly at the sentence level \citep{blatz2003confidence, callison2006re}. Its primary weakness is a strict reliance on surface-level string matching, which fails to reward valid paraphrases or semantic equivalence. This is especially problematic for morphologically rich or syntactically flexible languages like Czech, where even grammatically and semantically correct translations may be penalized for differing word order or inflectional forms \citep{bojar-tackling-sparse-data}. Furthermore, since \bleu does not explicitly model recall, it often fails to account for content coverage \citep{banerjee-lavie-2005-meteor}.

Despite these flaws, \bleu remains the \textit{de facto} standard in machine translation evaluation. As already mentioned, \cite{marie-etal-2021-scientific} found that 99\% of MT research papers published between 2010 and 2021 relied on \bleu for system comparison. However, recent large-scale meta-evaluations \cite{mathur-etal-2020-tangled, freitag-etal-2022-results} demonstrate that overlap-based metrics correlate substantially less with human judgments than modern neural metrics. Over-reliance on \bleu may therefore obscure differences between systems and mislead research conclusions. In 2026, while \bleu remains a useful legacy benchmark, it is no longer considered a sufficient measure of semantic adequacy.

\subsubsection{\ter}
Translation Error Rate (\ter) \citep{ter} evaluates the quality of machine translations by measuring the amount of editing operations needed to make a machine-translated text match a human-translated reference. Essentially, it quantifies the effort required to `fix' the machine translation output. 

Formally, given a machine translation hypothesis H and a reference translation R, the edit distance E is defined as the number of the following four editing operations required to transform H into R: 

\begin{itemize}
    \item  Insertion: Adding a single token to H.
    \item  Deletion: Removing a single token from H.
    \item  Substitution: Replacing one token in H with another.
    \item  Shift: Moving a contiguous block of tokens within H to better align with R.
\end{itemize}

\ter is then computed as:

$$\ter = \frac{E}{|R|},$$

where $|R|$ denotes the number of tokens in the reference (or the average across multiple references). Lower \ter indicates better translation quality, directly corresponding to a reduced editing effort. If there are multiple references, the minimum error rate across references is typically used.

\cite{ter} show that the single-reference variant of \ter correlates as well with human judgments of MT quality as the four-reference variant of \bleu. \cite{agarwal-lavie-2008-meteor} explore metric variants tuned for better human correlation in the WMT08 shared task. They compare \meteor \cite{meteor07}, \textsc{M-\bleu} (\bleu with improved preprocessing), and \textsc{M-TER} (\ter with the same preprocessing) and find that \textsc{M-TER} achieves the highest system-level correlation with human rankings, surpassing both \textsc{M-}\bleu and \meteor (See in \Cref{rw:meteor})


\subsubsection{\chrf}
\chrf (Character n-gram F-score) \citep{popovic-2015-chrf} is a metric that computes a weighted F-score over character n-gram matches between the hypothesis and reference translations. It is particularly effective in scenarios where word-level matches are sparse, such as in morphologically rich languages where a hypothesis might share roots with the reference but differ in inflection. Unlike \bleu, which focuses on precision and uses a brevity penalty as a proxy for recall, \chrf directly incorporates both precision and recall, making it more sensitive to partial matches and morphological variations.

Formally, the \chrf score is calculated as the $F_\beta$-score of  character n-gram precision ($P$) and recall ($R$):

$$\text{\chrf}\beta = (1 + \beta^2) \cdot \frac{P \cdot R}{\beta^2 \cdot P + R} ,$$
 
where $\beta$ is a parameter that assigns $\beta^2$ times more importance to recall than to precision. While $\beta = 1$ would result in a symmetric harmonic mean, the standard implementation of \chrf commonly sets  $\beta = 2$ (\chrf{2}), deliberately favoring recall to better align with human judgments of adequacy.

\chrfp \citep{popovic-2017-chrf} extends \chrf by incorporating word-level n-gram F-scores alongside  character-level n-grams. This hybrid approach captures both local character-level similarity and broader syntactic patterns at the word level. The inclusion of word n-grams allows \chrfp to better capture fluency, while maintaining the robustness of character-level matching. 

The combined metric leverages a weighted average of the character-level F-score ($\text{\chrf}_{\text{char}}$) and the word-level F-score ($\text{\chrf}_{\text{word}}$):

$$\text{\chrfp} = \lambda \cdot \text{\chrf}_{\text{char}} + (1 - \lambda) \cdot \text{\chrf}_{\text{word}},$$

where $\lambda \in [0,1]$ controls the relative importance of character and word components.

\subsection{String-matching metrics with linguistic resources}

To address the limitations of strict string matching, specifically its inability to capture semantic equivalence, second-generation metrics incorporate linguistic resources. These metrics move beyond surface-level identity by utilizing stemming, synonym dictionaries, or pre-computed paraphrase tables to identify matches that are lexically different but semantically identical.

Beyond simple lexical variation, more sophisticated frameworks have been proposed to leverage rich linguistic features, including part-of-speech (POS) tagging, dependency parse trees, and textual entailment \citep{liu:2005, owczarzak:2007, Pado09, han-etal-2012-lepor}. While these strategies are more discriminative and better reflect human perception than basic n-gram overlap, they introduce a significant trade-off in terms of universal applicability. Unlike the language-agnostic nature of \bleu, paraphrase-aware metrics rely heavily on language-specific resources. Because such resources are mostly available in English, the ``universal applicability'' is sacrificed for better correlation with human judgment in specific language pairs.

Nowadays, these feature-engineered methods are largely considered legacy. While they were historically significant for introducing recall and semantic flexibility into evaluation, they have been replaced by the implicit semantic modeling of neural architectures. Nevertheless, they remain important benchmarks for understanding the transition from symbolic to neural evaluation. In the following sections, we examine two prominent examples of this approach: \terp and \mn.

\subsubsection{\terp}
\terp (Translation Error Rate plus\footnote{While the original \ter is a literal acronym, \terp is named after the Terrapin, the mascot of the University of Maryland, where the metric was developed \citep{terp}.}, \cite{terp}) extends the original Translation Error Rate (\ter) metric. 

Like \ter, \terp measures the number of edit operations required to transform a hypothesis into a reference. It uses the four basic edit operations—Insertion, Deletion, Substitution, and Shift—but augments them with following linguistically informed substitutions:

\begin{itemize}
    \item Stem Substitutions: words are considered matches if they share the same stem, typically determined using the Porter stemming algorithm \citep{porter1980algorithm}
    \item Synonym Substitutions: words are matched if they belong to the same synset in WordNet \citep{fellbaum98wordnet}.
    \item Phrase Substitutions: phrase substitutions are identified using automatically extracted paraphrase tables, obtained via pivot-based methods applied to bilingual parallel corpora \citep{pivoting}.
\end{itemize}

Because these additional edit operations differ in their linguistic nature from the original TER operations, \terp introduces distinct weights for each edit type. This enables the metric to model varying degrees of error severity; for example, the cost of a synonym substitution is typically set lower than that of an unrelated lexical substitution, reflecting a smaller semantic deviation. 

Formally, \terp is computed as a weighted sum of edits normalized by the reference length ($|R|$):

$$\terp = \frac{\sum_i c_i \cdot e_i}{|R|},$$

where $e_i$ is the number of the edit operation $i$,  $c_i$ is the corresponding cost (weight) of operation$i$.
As with \ter, lower \terp scores indicate better translation quality, directly corresponding to a reduction in required editing effort. 

\citet{snover-etal-2009-fluency} report that \terp achieves a significantly higher correlation with human judgments than the original \ter metric. This suggests that incorporating linguistically informed substitutions allows the metric to more accurately distinguish between stylistic variation and actual translation errors.

\subsubsection{\mn}
\label{rw:meteor}
In \citeyear{banerjee-lavie-2005-meteor}, \citeauthor{banerjee-lavie-2005-meteor} introduced \meteor (Metric for Evaluation of Translation with Explicit Ordering),  to address specific shortcomings of the \bleu metric, such as its lack of recall, reliance on exact n-gram matching, and the use of geometric averaging.

In this section, we provide a detailed description of a subsequent version of the \meteor metric, known as \mn\footnote{There is a newer version 1.5 of \mn introduced in \cite{denkowski-lavie-2014-meteor}, which is computed slightly differently --- it also distinguishes between content and function words. However, we describe in more detail the previous version 1.4 as it was used in our experiments.}, which was introduced together with \mpt in \cite{meteor-tables}. We present \mpt in more detail in \Cref{meteori}.

\mn evaluates a hypothesis by first constructing a word-level alignment with the reference. The alignment is produced by identifying all possible matches using the following hierarchical criteria:

In the first step, the search space of possible alignments is constructed. For a single hypothesis-reference pair, the space of possible alignments is constructed by identifying all possible matches of words and phrases between the two sentences, using the following matching criteria: 

\begin{itemize}
    \item \textbf{Exact matching:} Surface forms must be identical.
    \item \textbf{Stem matching:} Words share the same stem via a Snowball Stemmer \citep{snowball}.
    \item \textbf{Synonym matching:} Words belong to the same WordNet synset \citep{fellbaum98wordnet}. 
    \item \textbf{Paraphrase matching:} Phrases are identified in the \mpt. 
\end{itemize}

In its basic configuration for evaluating Czech sentences, \mn supports two types of matching: exact and paraphrase. However, as discussed in \Cref{parmesan}, Czech paraphrase tables contain a lot of noise (pairs that do not actually represent true paraphrases), which harms the performance of the metric, occasionally rewarding mistranslations or non-translated terms.

After selecting the alignment that maximizes coverage, the metric computes precision ($P$) and recall ($R$). These are combined into a weighted F-score ($F_{\text{mean}}$), typically with more emphasis added on recall ($\alpha$ is usually set to 0.9):

$$
P = \frac{m}{|\text{H}|}, \qquad
R = \frac{m}{|\text{R}|}, \qquad
F_{\text{mean}} = \frac{P \cdot R}{\alpha P + (1 - \alpha) R},
$$

where $m$ is the number of aligned words, and $\lvert H\rvert$ and $\lvert R\rvert$ are the lengths of the hypothesis and reference, respectively. Note that with $\alpha=0.9$, this formulation is mathematically equivalent to an $F_\beta$ score with $\beta=3$.

To account for word-order differences, \mn penalizes alignments based on the number of chunks $ch$, i.e., contiguous segments of aligned words and the total number of matched words$m$. The penalty is computed:

$$
Pen = \gamma \times \left(\frac{ch}{m}\right)^\beta, 
$$

where the default parameter values are typically $\gamma = 0.5$, $\beta = 3$. The penalty is higher if words are matched but not in the correct order (more chunks). Finally, the \mn score combines the F-score and the penalty:

$$
\text{\mn} = (1 - Pen) \times F_{\text{mean}} $$
%= \left(1 - \gamma \times \left(\frac{ch}{m}\right)^\beta\right) \times \frac{P \times R}{\alpha \times P + (1 - \alpha) \times R} $$

This results in a single value, ranging from 0 (no similarity) to 1 (perfect match). In the case of multiple references provided, the hypothesis is compared against each reference separately and the highest score is selected. 

\mn generally performs better than \bleu in WMT evaluations; however, it has its own issues. For example, it can be overly permissive in its matching, aligning words that are technically synonyms but contextually inappropriate, or even non-synonyms due to noise in the paraphrase tables. This can lead to inflated scores for poor-quality translations. To mitigate this, \citet{guo-hu-2019-meteor} extended \mn with syntactic paraphrases from the Paraphrase Database (PPDB; \cite{pavlick-etal-2015-ppdb}). Their results show that this extended version, which better accounts for structural variations, further improves correlation with human judgments of translation quality.

\subsection{Embedding-based metrics}
The field of MT evaluation has experienced a gradual shift from surface-level string matching toward neural embedding-based metrics. \cite{marie-etal-2021-scientific} reported that 82\% of MT papers in 2019--2020 relied solely on \bleu and that 89\% of the newly proposed MT evaluation metrics have never been reused since their introduction. However, the widespread adoption of pre-trained neural representations has led to the development of metrics with significantly higher human correlation. In the following sections, we describe in more detail  \comet~\citep{rei-etal-2020-comet}, \bertscore~\citep{bertscore:2020}, and \bleurt \citep{sellam-etal-2020-bleurt}, which have gained considerable popularity in the community, each receiving over one thousand citations. 

Embedding-based metrics leverage contextual representations from models like BERT \cite{bert} or XLM-R \cite{xlm-r} to compare translations in a semantic vector space. This allows for a more detailed evaluation of meaning preservation than traditional n-gram overlap. However, this is also their weakness --- because the embeddings spaces tend to cluster semantically or syntactically similar tokens, embedding-based metrics might be vulnerable to critical errors involving numerical values and named entities. Such elements can have similar embeddings to incorrect alternatives, potentially leading to overly optimistic evaluations of flawed translations.

Neural evaluation metrics differ primarily in how they utilize semantic representations and what data they are trained on. They generally fall into two categories:
\begin{itemize}
    \item \textbf{Unsupervised (Direct Similarity):} Metrics like \bertscore, \textsc{YiSi} \citep{lo-2019-yisi} or \textsc{UniTE} \citep{wan-etal-2022-unite}, compute similarity directly using measures like cosine similarity or contextual alignment.
    \item \textbf{Supervised (Regression-based):} Regression metrics like \comet and \bleurt are fine-tuned on human-annotated data (DA or MQM) to predict an absolute quality score.
\end{itemize}
   
Embedding-based metrics are typically open-source, reproducible, and  efficient to compute compared to LLMs, which make them better suited for integration into development workflows. In the following sections, we present an overview of the most widely used embedding-based metrics for machine translation evaluation.

\subsubsection{Unsupervised} 
\noindent\paragraph{\bertscore} \citep{bertscore:2020} is a reference-based metric that does not require a source sentence. Specifically, for each token in a hypothesis, \bertscore identifies the most similar token in the reference, and vice versa. These similarity scores are then aggregated to compute precision, recall, and F1 scores that reflect how well the hypothesis preserves the meaning of the reference. In this formulation, recall captures how much of the reference content is covered and precision assesses how much of the hypothesis is semantically relevant.

It is fully unsupervised and does not involve any fine-tuning on human judgment data, which makes it fast and easy to apply across various domains and language pairs. It also supports multilingual evaluation when used with appropriate multilingual models like XLM-R.

Empirical evaluations in the original article and subsequent benchmarks~\citep{hanna-bojar-2021-fine, freitag-etal-2022-results} demonstrate that \bertscore correlates better with human judgments than \bleu and other traditional metrics, especially at the segment level. %It is available as an easy-to-use Python package with a command-line interface and integration with the Hugging Face Transformers library.

Despite its advantages, one limitation of \bertscore is its sensitivity to token alignment and strong reliance on embedding similarity, which may not always reflect nuanced translation errors or pragmatic changes. However, it remains a popular and accessible metric, particularly useful for tasks that emphasize semantic adequacy.

\subsubsection{Supervised}
\noindent\paragraph{\comet} (Crosslingual Optimized Metric for Evaluation of Translation; \citep{rei-etal-2020-comet}) is built upon a multilingual transformer architecture, XLM-RoBERTa~\citep{xlm-r} is used as the default encoder. \comet incorporates contextual representations of the source sentence, the machine-translated hypothesis, and the reference translation. These representations are pooled and passed into a shallow feedforward neural network trained to predict human quality judgments.

The standard training objective is regression\footnote{In addition to regression-based models, there are also ranking and unified objectives.}, optimizing the model to align its predictions with human-assigned DA and MQM scores collected through WMT evaluation campaigns.

There are several pretrained models available for the \comet framework, such as the reference-based \texttt{Unbabel/wmt22-comet-da} and the reference-free \texttt{Unbabel/wmt22-cometkiwi-da}, both trained on DA data from WMT17 to WMT20. These models predict scores ranging from 0 to 1, where 1 denotes a perfect translation. In particular, the \comet framework is fully open source,\footnote{\url{https://github.com/Unbabel/COMET.git}} allowing researchers to train custom models for specific domains or objectives.

Empirical evaluations, particularly in recent WMT Metrics shared tasks~\citep{freitag-etal-2021-results, freitag-etal-2022-results, freitag-etal-2023-results}, have shown that \comet models consistently outperform traditional lexical-based metrics in terms of correlation with human judgments across a wide range of language pairs and domains. As a result, \comet is becoming one of the most popular evaluation metrics in machine translation research.

\noindent\paragraph{\bleurt} (Bilingual Evaluation Understudy with Representations from Transformers) is a neural machine translation evaluation metric introduced by~\citet{sellam-etal-2020-bleurt}. It combines contextual embeddings pre-trained from BERT~\citep{bert} with supervised fine-tuning on human-annotated quality data to produce a scalar score that reflects translation adequacy. \bleurt is a reference-based metric --- it compares a machine-generated hypothesis to one or more reference translations but does not use the source sentence.

The \bleurt framework begins with a BERT-based encoder pre-trained in general language understanding tasks and is further pre-trained on large-scale synthetic data that simulate translation-like noise. It is then fine-tuned on human ratings of MT quality (e.g., DA scores from WMT shared tasks), enabling the model to learn subtle patterns of semantic variation, fluency issues, and adequacy mismatches that go beyond simple token-level similarity.

\bleurt outputs a real-valued score, typically between 0 and 1, where higher values indicate greater semantic similarity and translation quality. It has been shown to outperform traditional metrics and several other neural approaches in terms of correlation with human judgments, especially at the sentence level~\citep{sellam-etal-2020-bleurt}. As a result, \bleurt is often used in model evaluation, tuning, and even as an auxiliary training signal in MT systems.

A key strength of \bleurt is its ability to capture nuanced differences in meaning and phrasing. However, like other fine-tuned metrics, it is only as good as the data on which it was trained; its generalization may be limited for low-resource languages or domains far from its training distribution.

\subsection{Probabilistic models}
A distinct line of work considers translation evaluation as a probabilistic generation problem rather than relying on learned quality scores or direct embedding similarity. The most prominent probabilistic metric is \textsc{Prism}.
\textsc{Prism} can be interpreted as a probabilistic analogue to embedding-based metrics, where semantic similarity is captured through generation likelihood rather than vector similarity.  It serves as an important conceptual stepping stone from embedding-based similarity toward generative and LLM-based evaluation paradigms, shifting the focus from static vector comparisons to probabilistic generation likelihood.

\subsubsection{Prism}
\textsc{Prism} \citep{prism} is a probabilistic evaluation metric based on an NMT system for paraphrasing as a zero-shot translation task. Instead of relying on surface-level overlap with reference translations, Prism uses a multilingual sequence-to-sequence model trained for paraphrasing. At evaluation time, it computes the probability of generating a hypothesis given a reference (or vice versa), effectively measuring semantic adequacy through conditional likelihood. Because the underlying model is multilingual, Prism can be applied across many language pairs without task-specific training data. Prism outperformed or matched all other metrics on WMT 2019 segment-level shared metrics task \citep{prism}.


\subsection{LLM as Judge}
In recent years, large language model-based metrics have emerged as strong alternatives to fine-tuned encoder-based metrics such as \comet. These approaches prompt general-purpose LLMs to act as judges (e.g., \textsc{GEMBA}~\citep{kocmi-federmann-2023-gemba}) or utilize LLMs fine-tuned specifically for quality estimation, i.e. reference-free MT evaluation (e.g., \textsc{MetricX-24}~\citep{juraska-etal-2024-metricx}). \textsc{GEMBA} and \textsc{MetricX-24} achieved both state-of-the-art system-level correlations in WMT23 \citep{kocmi-etal-2023-findings} and WMT24 \citep{kocmi-etal-2024-findings}, respectively, often surpassing established fine-tuned metrics such as \comet.

Despite their strong performance, LLM-based metrics have several important limitations. Earlier work reported weaker segment-level performance \citep{kocmi-federmann-2023-large,fernandes-etal-2023-devil}; however, recent approaches based on pairwise prompting, instruction tuning, and distillation have significantly narrowed this gap \citep{kocmi-etal-2024-navigating, tan-monz-2025-remedy}. Furthermore, they are also computationally expensive, typically operate as black boxes, which makes them difficult to audit or deploy efficiently in production pipelines.

Another major drawback of LLM-based evaluation metrics is their limited reproducibility and temporal instability. Many metrics depend on proprietary APIs (e.g., OpenAI, Anthropic) whose underlying models may change without notice. Consequently, scores produced today may differ from those obtained weeks or months later, even with identical inputs. This undermines their reliability for benchmarking or system-tuning workflows. Although setting deterministic decoding parameters (e.g. temperature = 0) and using static prompts can reduce some variability, LLM-based metrics remain inherently unstable unless deployed locally using frozen open-weight models, an option that is computationally demanding and not always feasible.

Recent works mitigate these issues via \textit{pairwise ranking}~\citep{kocmi-etal-2024-navigating} or \textit{distillation into smaller reward models}~\citep{tan-monz-2025-remedy}. While neural metrics fine-tuned on human judgment, such as \comet, currently dominate WMT benchmarks~\citep{freitag-etal-2024-llms}, general-purpose large language models are promising for zero-shot, multilingual, or explanation-rich evaluation \citep{kocmi-federmann-2023-gemba, fernandes-etal-2023-devil, leiter-etal-2023-eval4nlp, xu-etal-2023-instructscore, leiter-eger-2024-prexme}. For example, \textsc{Prometheus} \citep{kim-etal-2024-prometheus} utilizes frozen \textsc{LLaMA-2-70B-Chat} model with a simple static pairwise prompt: ``Compare these two translations and explain which is better.'' This setup achieves ~85\% pairwise accuracy on WMT23 data while ensuring full reproducibility via Hugging Face. Similarly, \textsc{AutoMQM}~\citep{fernandes-etal-2023-devil} uses \textsc{FLAN-T5-XXL} for zero-shot error detection, reporting stable segment-level correlations.

\subsection{Preference-trained metrics}
Recently, \textit{preference-trained} evaluation metrics have emerged as a strong alternative to regression-based approaches. These metrics fine-tune smaller (often open-weight) language models explicitly on human preferences (e.g., ``translation A is better than B''), rather than relying on DA or MQM annotations. This design choice has made it particularly robust on low-quality translations, where absolute scoring may be noisy or inconsistent.

Early approaches such as \mtranker \citep{Moosa2024MTRankerRM} demonstrated the effectiveness of this paradigm. More recent work, such as \remedy \citep{tan-monz-2025-remedy}, further improves performance by incorporating distillation and more advanced training strategies, achieving state-of-the-art results in recent WMT evaluations.


\section{Generating additional references}

The quality of human reference translations plays a critical role and can influence the outcome of the evaluation more significantly than the choice of metric itself \citep{freitag-etal-2020-bleu}. To address the limitations of relying on a single or limited set of references, researchers have explored methods to generate additional references through both manual and automatic approaches.

\subsection{Manual Paraphrasing Approaches}
There is evidence that paraphrasing reference translations improves the MT evaluation. \cite{bojar-scratching} demonstrated this with the \textit{Deprefset} dataset, where annotators attempted to create all possible paraphrases for 50 sentences from the WMT11 evaluation dataset \citep{wmt11}. Although correlation with human judgments improved, the process was highly labor intensive, and annotators were allowed to spend up to two hours per sentence. However, the annotators managed to generate hundreds of thousands of paraphrases per reference sentence, illustrating both the richness of linguistic variation and the computational challenges of exhaustive paraphrasing.

To reduce annotation costs,  \cite{bloodgood-callison-burch-2010-using} used crowd-sourcing platforms such as Amazon Mechanical Turk, enabling scalable paraphrase collection while maintaining acceptable quality. More recently, \cite{freitag-etal-2020-bleu} showed that human paraphrases lead to evaluation scores that correlate more strongly with expert judgments and can even improve system tuning. Interestingly, however, such systems may score lower under BLEU, highlighting a persistent misalignment between traditional n-gram–based metrics and human preferences.

\subsection{Automatic Paraphrasing}
\label{generating_paraphrases}
The concept of targeted paraphrasing for MT evaluation was introduced by \cite{kauchak}. Rather than generating all possible paraphrases, their approach focuses on creating synthetic references that are lexically closer to the system output while maintaining semantic equivalence with the original reference. Their approach is straightforward; it consists of the following four steps:

\begin{enumerate}
    \item \textbf{Candidate Selection}: The algorithm identifies pairs of words from the reference and the system output that could potentially form paraphrases, i.e. all pairs of words for which one word appears in a reference sentence, the second in a hypothesis, but none of them in both.
    \item\textbf{Candidate Filtering}: Only pairs of synonymous words, i.e. words appearing in the same WordNet \cite{wordnet} synset, were kept from the candidate pairs. 
    \item \textbf{Contextual Classification}: A classifier tests whether each candidate paraphrase is admissible in the  reference sentence, because words from a synset are not interchangeable in every context.    
    \item\textbf{Contextual Substitution}: For every confirmed synonym, a new reference sentence is created by placing it to the reference sentence on the position of its synonym. 
\end{enumerate}

Their experiments demonstrated that the use of such synthetic reference sentences improves the precision of automatic evaluation. Furthermore, they established a strong connection between the quality of automatic paraphrases, as assessed by humans, and their impact on automatic evaluation. %Unfortunately, their experiments were performed on Chinese-English translations only.

Other studies confirm these findings. \cite{madnani-etal-2007-using} show that paraphrased references, even noisy ones, reduce the number of human references needed to tune an SMT system, without significantly affecting MT quality. \cite{tamchyna-barancikova-2016-manual} proposed automatic dataset creation methods and compared manual versus automatic paraphrases for evaluation. We introduce in detail several methods of targeted paraphrasing of Czech reference sentences in \Cref{prehistory}.

Another approach is to use machine translation to create paraphrases by translating the source sentence. \cite{albrecht_2008} pioneered the use of off-the-shelf MT systems (including Systran, Google Translate, and Moses) to generate \textit{pseudo-references}, used both in direct evaluation and as features in learned metrics. This method showed improvements for most language pairs, though the results varied by target language. This method was improved more recently by \cite{yoshimura_2019a}, who again used standard MT systems (here Google Translate, Bing Translate) to translate the source sentences, and then filtered the translation using a BERT-based classifier trained on Microsoft Research Paraphrase Corpus (MRPC) \citep{dolan_2005}. We present experiments with SMT paraphrasing and rule-based paraphrasing in \Cref{moses} and \Cref{treex}, respectively.

While early targeted paraphrasing relied on discrete lexical substitution, the field has shifted toward a \textit{generation-based evaluation} paradigm. Modern approaches leverage the generative strength of large language models to overcome the \textit{generative AI paradox} \citep{west2023generativeaiparadoxwhat}, i.e., the observation that LLMs are often more capable of producing fluent, accurate translations than they are of providing consistent numeric quality scores \citep{cui2025llmsscorersrethinkingmt}. 

Instead of filtering word-pairs through WordNet, current methods like Div-Ref \citep{tang2024metricsguiltyimprovingnlg} use LLMs to expand a single human reference into a diverse ensemble of reference sentences. This ensemble captures the semantic variability of the target language, allowing metrics to reward correct translations that use different syntactic structures or synonyms not present in the original gold standard. However, this shift introduces new challenges, such as the \textit{self-preference bias}, where LLM-based metrics may unfairly favor translations that mimic their own generative style over human-authored ones.

\section{Automatic Metrics Evaluation}
The performance of an automatic machine translation evaluation metric is usually computed as the Pearson correlation between automatic metric scores and human judgments. The~correlation estimates the linear dependency between two sets of values.

The Pearson correlation coefficient $\rho$ is defined by the following formula:

\begin{equation*}
\rho(H,M) = \frac{ \sum_{i=1}^{n}{(H_i - \tilde{H})(M_i - \tilde{M})}}{ \sqrt{ \sum_{i=1}^{n}{(H_i - \tilde{H})^2} }  \sqrt{ \sum_{i=1}^{n}{(M_i - \tilde{M})^2} } } 
\end{equation*}
where $H$ is the vector of human scores and $M$ is the vector of corresponding scores predicted by a certain metric. $\tilde{H}$ and $\tilde{M}$ are their means, respectively. 

Alternatively, the Spearman correlation coefficient $r_{s} $ is defined as the Pearson correlation coefficient between the rank variables -- all human scores and  metric’s scores of MT systems are converted into ranks $r(H)$ and $r(M)$, i.e., their order from the best to the worst.

\begin{equation*}
r_{s}(H,M) = \rho(r(H),r(M))
\end{equation*}

Both~correlations measure the strength of association between two sets of values and range from -1 (perfect negative linear relationship) to 1 (perfect linear correlation). 

In our experiments, we use the Pearson correlation coefficient, as it takes into account the distances between the system scores, thus it should be more reliable for similarly evaluated systems \citep{machacek-bojar-2014-results}.
